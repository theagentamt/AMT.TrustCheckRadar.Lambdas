# Candidate.3 rules-only profile 1

This immutable Dev source profile binds the existing
`1.0.0-message-candidate.3` transport to the trusted rules-only runtime mode.
It is not a new public transport version and does not activate the profile.

Both the consumer and evaluator must receive
`MESSAGE_CANDIDATE3_RULES_ONLY_ENABLED=true`; AI and external URL reputation
remain disabled. The fixtures are synthetic. They contain no user content,
provider output, secret, account identifier, entitlement, or operation proof.

`evaluation-fixtures.json` covers qualified English and Spanish rules,
unsupported and withheld-link inputs, and the hostile-input stop. Every expected
outcome is generated by the local evaluator with provider and AI callables that
fail the test if invoked. `transport-state-fixtures.json` records the exact
closed and retry boundaries already enforced by the candidate.3 response
contract. Source tests validate those boundaries through the real consumer.
