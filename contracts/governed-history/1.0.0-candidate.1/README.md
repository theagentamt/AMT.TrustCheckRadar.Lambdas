# Governed result History candidate.1

This default-off Dev contract exposes only:

- `GET /v1/users/analysis-history?cursor=&limit=`
- `GET /v1/users/analysis-history/{resultId}`

Items are typed, content-free projections committed with an authoritative URL
candidate.2 or message candidate.3 settlement. They contain no submitted or
sanitized content, URL, entity, image, operation proof, current entitlement, or
free-form explanation. Pending, pre-admission, no-summary, and legacy results are
not represented.

The deadline is exactly seven days from the original settlement and never moves
on list, detail, retry, reconciliation, or freshness presentation. Accounting is
the original settlement accounting. `outcome` is the original typed settlement
outcome, including the original provider observation and deadline. The separate
`presentation` object reports current or historical display semantics. Read-time
freshness can make that presentation conservative; it cannot renew evidence,
call a provider, rewrite the original outcome, or charge another check.

The opaque cursor expires after 15 minutes and is bound to the account, active
device version, verified HMAC-key inventory revision, contract, and page boundary.
Both routes require separate default-off gates. Export, recognition, mutation,
legacy History, and operator functions are outside this contract.
